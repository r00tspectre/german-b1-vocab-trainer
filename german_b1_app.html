Definite Articles — der / die / das
CaseMasc.Fem.Neut.Plural
Nom der die das die
Acc den die das die
Dat dem der dem den
Gen des der des der
Key pattern: Only Acc masc. changes (der→den). Fem/Neut Nom=Acc. Dat masc/neut both use dem; Dat fem uses der.
Indefinite Articles — ein / eine
CaseMasc.Fem.Neut.
Nom ein eine ein
Acc einen eine ein
Dat einem einer einem
Gen eines einer eines
No plural: Use keine / keine / keinen / keiner for negation in plural. ein follows the same endings as kein / mein / dein…
